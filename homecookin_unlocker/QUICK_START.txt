家常音樂 · 彩蛋解鎖工具 0.2

這是桌面視窗程式，不需要安裝 Python 或輸入指令。

開始使用
1. 解壓縮下載的 ZIP。
2. Windows：雙擊 HomeCookinUnlocker.exe。
   Mac：雙擊 HomeCookinUnlocker.app。
3. 工具會自動尋找原版《運河》的存檔。
4. 完全關閉遊戲，勾選「我已完全關閉遊戲」。
5. 按「備份並開啟彩蛋資格」。看到完成提示後即可關閉工具。
6. 回到遊戲，選擇「繼續遊戲」。第四章向唱片行詢問《家常音樂》，再回到街道探索。

找不到存檔？
先在遊戲中跳過登入、開始遊戲並完成一次存檔，再完全關閉遊戲。
如果存檔放在其他位置，按「選擇存檔」，選取 save.dat。

顯示「需要較早的存檔」？
表示目前已超過彩蛋分岔點或走進其他分支。請選擇較早的存檔。
工具不會重設劇情或移除道具，也不能讓已完成的彩蛋重播。

想恢復原本進度？
按「還原備份」，選擇清單中的時間並確認。
還原的是當時整份進度，後來的任務和道具也會回到當時狀態；目前存檔會先備份。

相容性
目前依 Windows 原版 1.0.0 的存檔格式製作。
這是測試版，遊戲內彩蛋完整流程及 Mac 存檔相容性仍待實機驗證。
未簽署的測試版本可能受到 Windows / macOS 下載保護攔截。
供一般玩家使用的 Mac 正式版應完成開發者簽署與 Apple 公證。

所有存檔操作都在本機完成，不需要官網帳號密碼。
