# 運河散策・完整圖文攻略

直接以 Chrome、Edge 或 Firefox 開啟 `index.html`，不需要安裝、啟動伺服器或連上網路。解壓縮後請保留整個資料夾，圖片與資料不可分開搬移。

## 收錄內容

- 原版 SL 遊戲的 294 組索引事件；293 組附圖，夜店學生版 GorDoN 1 組待補。
- 736 段原始對話，加上 4 段選項額外回覆，共 740 段圖文對照項目；目前提供 734 張修正版畫面，另 6 段保留原文並標為待補。
- 主線章節導讀、GorDoN 等支線提示、完整原文與逐段畫面對照。
- 全文搜尋、場景／章節篩選、已讀標記、收藏與個人筆記。
- 手機版版面、圖片放大、單篇列印與閱讀進度匯出／匯入。

攻略包含劇情及支線解答。第 1–10 章章名取自原版任務表，第 11–12 章標題為攻略整理。

## 使用方式

點擊事件卡片開啟詳情；點擊對話原文會跳到相對應的畫面。圖片下方可翻頁，也可使用鍵盤左右鍵；Esc 關閉，首頁按 / 可搜尋。手機可使用畫面上的按鈕操作。

已讀、收藏及筆記保存在目前瀏覽器。搬動資料夾、切換瀏覽器或清除瀏覽資料前，先匯出閱讀進度，再於新位置匯入。原始 story_index.md 的勾選與網頁閱讀進度各自保存。

「列印本篇」會列出目前事件的所有畫面與文字；可在瀏覽器列印視窗選擇另存 PDF。

## 截圖與考證範圍

本攻略使用原版引擎、原始場景素材、SL 角色與原生對話框，透過事件預覽功能逐段重現。這些是**事件重現截圖**，並非全部分支皆由新遊戲自然實玩到達的紀錄。鏡頭與角色站位經整理；自動劇情或找不到獨立互動點的事件，以相關場景配圖，站位不代表觸發方法。畫面不保證重現每段事件伴隨的完整動作與過場。

156 組事件對應原版地圖位置，119 組具有互動表規則。互動表條件是候選條件，對話優先序、NPC 與劇情狀態仍可能影響出現方式；未確認的獨立觸發方式不作保證。收錄範圍為 story_index.md 的全部 294 組事件，不含索引之外的音樂過場或純動作。

`data/story_index.md` 保留原索引快照，`data/coverage.json` 列出每組事件對應的圖片與 SHA-256。`data/source.json` 保存原版來源摘要與地圖依據。`verification/` 保存自動核對結果及版面檢查截圖。

遊戲素材與原文屬原作品；本攻略為非官方整理。

## 圖片壓縮版

全套截圖以本機 AVIF 4:4:4 高品質壓縮，保留 1200×900 原尺寸，不裁切、不重新繪製圖片。每張編碼後重新解碼，檢查全圖及對話區域誤差；不達門檻時提高品質，無縮小優勢時保留 JPEG。這是高品質有損壓縮，不宣稱像素完全不變。

圖片總量由 193.4 MiB 降至 112.6 MiB，減少 41.8%。仍為 734 張原版圖、740 個逐句畫面對照。AVIF 需要可解碼此格式的瀏覽器，已使用 Edge 檢查。原始 JPEG 保留在工作目錄的 `capture_masters/images/`，不包含在網頁及部署包內。
