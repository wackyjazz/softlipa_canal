# 運河散策・圖文攻略

收錄293組故事與互動、734張逐段畫面，包含主線路書、支線提示、人物對話、素材圖庫與歌詞閱讀。攻略含劇透。

## 使用方式

- 依主線路書前進，或搜尋人物、事件與台詞。
- 點擊事件卡片查看出現條件、操作方式與對話；點擊台詞可跳到相應截圖。
- 左右箭頭切換圖片，Esc關閉詳情；首頁按 / 可搜尋對話。
- 收藏、已讀與個人筆記保存在目前瀏覽器，換裝置前請先匯出備份。
- 「列印本篇」可列印完整圖文，也可另存為PDF。

## 圖片與遊戲

畫面使用原版遊戲場景與對話重現，實際人物動作或鏡頭可能略有不同。

網站版需要網路載入圖片；完整離線版請保留整個解壓縮資料夾，以Chrome、Edge或Firefox開啟index.html。

《運河 幻の南都》為蛋堡杜振熙《運河》專輯附贈遊戲。本站僅為非官方遊戲攻略，圖片與原文屬原作品；歡迎前往[任性的人官網](https://rsdr.online/)支持專輯。
