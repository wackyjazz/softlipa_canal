# 攻略內的視覺素材圖庫

開啟 index.html。收錄原始圖像 309 個、拆圖與場景合成 229 項，加上 4 篇石牌文字，共 542 項目錄，以及 3,202 格動畫。使用關鍵字、分類、逐格檢視、原尺寸放大與收藏清單匯入／匯出。搜尋和素材網址可以複製。

完整素材包 full_asset_pack 另含音訊、字型、地圖 JSON 與 shader；不納入網頁下載。所有原圖、透明背景與動畫圖格均完整保留；縮圖以無損 WebP 顯示。完整範圍與限制請見專案 HANDOFF_ASSETS_AND_WEB.md。

場景為原始美術圖層合成，未含執行時人物、道具、塗鴉和特效。彩蛋關鍵字為探索線索，不表示確認存在獨立事件。

## 石牌文字典藏

新增署名「佚名」的〈談選擇〉四篇：東區（之一，原題使用「之ㄧ」）、安平（之二）、北區（之三）、南區（之四）。原始程式分別保存文字陣列，原始地圖提供對應石牌物件；不是只有 UI 底圖。網頁以橫排方便閱讀，完整保留原文、分行、標點及空行，不將網頁排版當成遊戲截圖。

可搜尋篇名、佚名、石牌、石碑、地區與原文句子，收藏／匯出清單、複製網址及下載 UTF-8 原文。`steles/source.json` 記錄來源與校驗。以 `python3 asset_tools/add_steles.py` 從保留的原始 ASAR 重新擷取。

### 石牌翻頁與原文閱讀

點選石牌預設開啟原始底圖與金色直排文字，使用原始 Cubic 字型。分頁依遊戲原本的15欄及中英文字切分規則：之一／之二各2頁，之三／之四各5頁。左箭頭下一頁，右箭頭上一頁，亦可按左右方向鍵。可放大石牌；「原文閱讀」保留完整橫排，切換模式保留頁數。複製目前網址可直接開啟該頁及閱讀模式。
